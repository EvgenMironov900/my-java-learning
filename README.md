# ☕ Моё путешествие в мир Java

Этот репозиторий — **дубликат облачного хранилища** моего Java-проекта, 
начатого более **4 лет назад** на стареньком ноутбуке.

## 📚 Что здесь хранится:
- ✅ **Примеры из книги** "Java. Полное руководство" (Герберт Шилдт)
- ✅ **Мои собственные наработки** (`DirectoryExplorer.java`, `FindResults.java`)
- ✅ **Результаты работы** программ (папки с `Вывод.txt`)
- ✅ **Ошибки компиляции** (`Err.txt`) — чтобы помнить, на чём спотыкался

## 🗂️ Структура по страницам книги:
Каждая папка — **номер страницы** из Шилдта:
- `092/` — стр. 92 (динамическая инициализация)
- `101/` — стр. 101 (автоматические массивы)
- `135/` — стр. 135 (оператор switch)
- `205_1/` — стр. 205 (внутренние классы)
- `224/` — стр. 224 (super)
- `232/` — стр. 232 (переопределение методов)
- `247/` — стр. 247 (пакеты)
- `259/` — стр. 259 (вложенные интерфейсы)
- `280/` — стр. 280 (исключения)
- `282/` — стр. 282 (вложенные try)
- и так далее...

## 🔧 Технические детали:
- В репозитории **только исходники** (`.java`), никаких `.class` или `.jar`
- Скрипт `GitHubSays.sh` помогает чистить мусор перед коммитами
- `.gitignore` настроен, чтобы случайно не залить бинарники
